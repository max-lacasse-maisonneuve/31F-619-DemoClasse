# Exercice cours 11 - Introduction requêtes Fetch asynchrones vers PHP

## Consignes

1. Connectez-vous à une base de données MySQL avec PHP et importez la bdd `sondage.sql` dans le dossier `data`.

2. Dans le fichier `rechercher.php`, écrivez le code PHP nécessaire pour récupérer les données de la table sondage et les renvoyer au format JSON. Inspirez-vous du code en classe pour réaliser votre requête SQL et renvoyer les données au format JSON. Au besoin, rajoutez des données dans la table sondage pour tester votre code.

3. Au chargement de la page indexHTML, récupérez les données de la table sondage avec une requête HTTP GET et affichez-les dans le DOM.

## Notes

Vous devez utiliser l'api Fetch pour réaliser vos requêtes.
